# DSA Intelligencia — Expanded Catalog Edition

## What is included

- The original uploaded Striver + GFG tracker (316 rows before expansion).
- **523 additional curated practice rows** in the general problem library, tagged by pattern, platform, topic and difficulty.
- **447 additional company-prep rows** plus the existing starter company bank. Each question has one or more practice-cluster tags (Amazon, Google, Flipkart, Microsoft, Meta, Adobe, Uber, Bloomberg, Walmart, Samsung, Oracle, Goldman Sachs, Salesforce, Atlassian, etc.).
- A dedicated Pattern dropdown in the problem library, alongside platform, difficulty, status and track filters.
- Practice Studio links to the problem URL, alternate/GFG search, official TUF roadmap and relevant YouTube search when available.
- Existing CRUD for question records, solution editors for brute force and optimized approaches, TXT import/export, attempt history, revision, bookmarks, JSON backups and CSV export.
- A Source Library page with the official sheets, public GitHub catalogs, Codeforces/CSES and YouTube walkthrough references.

## Files

- `DSA_Intelligencia.html` — standalone app. Open it in Chrome or Edge.
- `DSA_Intelligencia_Expanded_Catalog.json` — machine-readable catalog of new questions added by this build.
- `DSA_Intelligencia_Expanded_Catalog.csv` — spreadsheet-compatible catalog export.

## Sources and how to use them

1. TakeUForward Striver A2Z: https://takeuforward.org/prep-hub/strivers-a2z-dsa-sheet
2. TakeUForward Striver 150: https://takeuforward.org/prep-hub/strivers-150-master-patterns-in-dsa
3. GeeksforGeeks Practice / GFG 160: https://www.geeksforgeeks.org/dsa/geeksforgeeks-practice-best-online-coding-platform/
4. LeetCode companywise question repository: https://github.com/snehasishroy/leetcode-companywise-interview-questions
5. LeetCode companywise public lists: https://github.com/liquidslr/leetcode-company-wise-problems
6. NeetCode-style reference repository: https://github.com/neetcode-gh/leetcode
7. NeetCode 150 walkthrough (YouTube): https://www.youtube.com/watch?v=T0u5nwSA0w0
8. Codeforces problemset: https://codeforces.com/problemset
9. CSES Problem Set: https://cses.fi/problemset/

**Important accuracy note:** this is a broad, curated, link-based offline catalog, not a live synchronization of every question on every platform. Official platform sheets can change. Some GFG links open an on-site search page instead of a hard-coded slug so that renamed or platform-specific statements can still be found. The app links to original sources rather than copying full problem statements. Company tags are interview-practice clusters and are **not** a verified claim that a particular employer asked the exact problem; verify provenance and recency in the source repository.

## Save progress

The standalone version saves locally in the current browser profile. Use **Backup** to export a JSON backup and **Import** to restore it. The new built-in company questions are merged in when an older local profile or backup is opened, without removing existing custom company questions. Back up before clearing browser data or moving to another device.
