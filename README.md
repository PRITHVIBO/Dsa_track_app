# DSA Intelligencia — DSA Practice Studio & Company Prep

## Start
1. Open `DSA_Intelligencia.html` in Chrome or Edge.
2. Use **Problem Library** or **Patterns & Topics** to choose a question from your imported Striver + GFG tracker.
3. Click **Practice** to open the Practice Studio. Open the original platform problem, solve it there, and return to save both brute-force and optimized solutions.
4. Log each attempt with date, approach, outcome, minutes, complexity, and mistake notes. Attempts can be created, edited, and deleted.
5. Download each solution as a plain `.txt` file, or export the full question record with both solutions and attempt history.
6. Open **Company Prep** for a separate interview-practice bank with company tags (Amazon, Google, Flipkart, Microsoft, Meta, Adobe, Uber, etc.). You can add, edit, delete, filter, or start practising any company question.

## Features
- Original imported Striver/GFG tracker preserved, with topic, difficulty, platform, status, and roadmap filters
- CRUD for personal questions and company questions; imported rows can be hidden/deleted from your local library
- Practice Studio with separate brute-force and optimized code editors and language selectors
- Save / import / download `.txt` solution files and export a consolidated practice-record `.txt`
- Attempt journal with create, edit, delete, result, time-spent, complexity, and notes
- Similar-question suggestions to continue practising the same pattern
- Company interview practice section with company filters and edit-ready curated question labels
- Progress, questions, attempts, company bank, and code included in JSON backup / import
- CSV exports the question bank and solution/attempt flags
- Local browser storage; no account or server required

## Important notes
- The company labels are curated practice groupings to guide preparation; they are not a guarantee that the company asked that exact problem in a specific interview. Company tags and interview patterns change.
- The app opens original problem links rather than copying full problem statements.
- Data is stored in the current browser profile. Export **Backup** regularly. Clearing browser data or moving to another computer will not transfer data unless you import your JSON backup.
- Code and long notes consume browser local-storage capacity. If the browser storage limit is reached, export a backup and remove older records as needed.
- Clear a saved brute-force or optimized solution directly from the Studio if you want to replace it or remove the stored code.
